# 接口测试文档

统一接口前缀：`/api/user-role`

默认 Base URL：`http://localhost:8080`

统一返回结构：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null
}
```

`code=200` 表示成功，`code=400` 表示参数校验失败，`code=500` 表示业务或系统异常。

---

## 1. 查询所有角色列表

### 接口名称

查询所有角色列表

### 请求方式

`GET`

### 完整 URL

```text
http://localhost:8080/api/user-role/roles
```

### 请求参数说明

无请求参数。

### 成功返回 JSON 示例

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [
    {
      "id": 1,
      "roleName": "管理员",
      "roleCode": "管理员",
      "description": "系统管理员"
    },
    {
      "id": 2,
      "roleName": "教师",
      "roleCode": "教师",
      "description": "教师角色"
    }
  ]
}
```

### 失败返回 JSON 示例

```json
{
  "code": 500,
  "message": "系统异常，请稍后重试",
  "data": null
}
```

### Postman 调用说明

1. 新建请求，请求方式选择 `GET`。
2. URL 填写 `http://localhost:8080/api/user-role/roles`。
3. 不需要 Header、Params、Body。
4. 点击 `Send`，返回 `code=200` 即成功。

---

## 2. 查询指定用户已拥有的角色 ID 列表

### 接口名称

查询指定用户已拥有的角色 ID 列表

### 请求方式

`GET`

### 完整 URL

```text
http://localhost:8080/api/user-role/user/{userId}/roles
```

示例：

```text
http://localhost:8080/api/user-role/user/1/roles
```

### 请求参数说明

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| userId | Path | Long | 是 | 用户 ID，必须为正整数 |

### 成功返回 JSON 示例

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [1, 2]
}
```

### 失败返回 JSON 示例

用户不存在：

```json
{
  "code": 500,
  "message": "用户不存在：9999",
  "data": null
}
```

userId 不合法：

```json
{
  "code": 400,
  "message": "userId 必须为正整数",
  "data": null
}
```

### Postman 调用说明

1. 新建请求，请求方式选择 `GET`。
2. URL 填写 `http://localhost:8080/api/user-role/user/1/roles`。
3. 不需要 Body。
4. 点击 `Send`，`data` 返回该用户已分配的角色 ID 数组，用于弹窗默认勾选。

---

## 3. 为用户分配角色

### 接口名称

为用户分配角色

### 请求方式

`POST`

### 完整 URL

```text
http://localhost:8080/api/user-role/user/{userId}/roles
```

示例：

```text
http://localhost:8080/api/user-role/user/1/roles
```

### 请求参数说明

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| userId | Path | Long | 是 | 用户 ID，必须为正整数 |
| roleIds | Body | Long[] | 是 | 角色 ID 列表，支持多选；空数组表示清除该用户全部角色 |

请求 Body 示例：

```json
{
  "roleIds": [1, 2, 3]
}
```

清除该用户全部角色：

```json
{
  "roleIds": []
}
```

### 成功返回 JSON 示例

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null
}
```

### 失败返回 JSON 示例

角色 ID 不存在：

```json
{
  "code": 500,
  "message": "存在无效的角色 ID",
  "data": null
}
```

缺少 roleIds：

```json
{
  "code": 400,
  "message": "roleIds 不能为 null",
  "data": null
}
```

### Postman 调用说明

1. 新建请求，请求方式选择 `POST`。
2. URL 填写 `http://localhost:8080/api/user-role/user/1/roles`。
3. 在 `Headers` 中添加 `Content-Type: application/json`。
4. 选择 `Body -> raw`，粘贴 `{"roleIds":[1,2]}`。
5. 点击 `Send`，返回 `code=200` 即分配成功。
6. 业务逻辑会先删除该用户原有角色，再批量插入新角色；重复的 roleId 会自动去重，空数组会清除全部角色。

## 4. 分页查询用户列表（带角色信息）

### 接口名称

分页查询用户列表（带角色信息）

### 请求方式

`GET`

### 完整 URL

```text
http://localhost:8080/api/user-role/users
```

带筛选示例：

```text
http://localhost:8080/api/user-role/users?pageNum=1&pageSize=10&username=zhang&name=张
```

### 请求参数说明

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| pageNum | Query | Integer | 否 | 页码，默认 1，最小 1 |
| pageSize | Query | Integer | 否 | 每页条数，默认 10，范围 1-100 |
| username | Query | String | 否 | 按用户名模糊查询 |
| name | Query | String | 否 | 按姓名模糊查询 |

### 成功返回 JSON 示例

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "pageNum": 1,
    "pageSize": 10,
    "total": 2,
    "records": [
      {
        "id": 1,
        "username": "zhangsan",
        "name": "张三",
        "roleIds": "1,2",
        "roleNames": "管理员,教师",
        "assigned": true
      },
      {
        "id": 2,
        "username": "lisi",
        "name": "李四",
        "roleIds": null,
        "roleNames": null,
        "assigned": false
      }
    ]
  }
}
```

### 失败返回 JSON 示例

pageSize 超出范围：

```json
{
  "code": 400,
  "message": "pageSize 不能超过 100",
  "data": null
}
```

### Postman 调用说明

1. 新建请求，请求方式选择 `GET`。
2. URL 填写 `http://localhost:8080/api/user-role/users?pageNum=1&pageSize=10`。
3. 如需要模糊查询，可在 URL 中追加 `&username=zhang` 或 `&name=张`。
4. 不需要 Body。
5. 点击 `Send`，`records` 中 `assigned=true` 表示该用户已分配角色，可展示“分配角色”按钮。

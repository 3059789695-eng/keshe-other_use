# 开课管理接口测试文档

统一接口前缀：`/api/course-opening`

> 说明：当前代码按现有 `course_offerings` 表实现，该表没有 `class_id`、`selected_count`，因此开课接口不再接收班级字段，也不返回班级/已选人数。

默认 Base URL：`http://localhost:8080`

统一返回结构：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null
}
```

`code=200` 表示成功，`code=400` 表示参数校验或业务校验失败，`code=500` 表示系统异常。

---

## 1. 分页查询开课列表

### 接口名称

分页查询开课列表

### 请求方式

`GET`

### 完整 URL

```text
http://localhost:8080/api/course-opening/page
```

带筛选示例：

```text
http://localhost:8080/api/course-opening/page?pageNum=1&pageSize=10&courseName=Java&semesterId=1&teacherName=张
```

### 请求参数说明

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| pageNum | Query | Integer | 否 | 页码，默认 1，最小 1 |
| pageSize | Query | Integer | 否 | 每页条数，默认 10，范围 1-100 |
| courseName | Query | String | 否 | 按课程名称模糊查询 |
| semesterId | Query | Integer | 否 | 按学期 ID 精确查询 |
| semesterName | Query | String | 否 | 按学期名称精确查询 |
| teacherName | Query | String | 否 | 按教师姓名模糊查询 |

### 成功返回 JSON 示例

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "pageNum": 1,
    "pageSize": 10,
    "total": 1,
    "records": [
      {
        "id": 1,
        "courseId": 1,
        "courseNo": "1",
        "courseName": "Java程序设计",
        "credit": 4.0,
        "semesterId": 1,
        "semesterName": "2025-2026-1",
        "teacherId": 1,
        "teacherName": "张老师",
        "maxStudents": 50
      }
    ]
  }
}
```

### 失败返回 JSON 示例

```json
{
  "code": 400,
  "message": "pageSize 不能超过 100",
  "data": null
}
```

### Postman 调用说明

1. 新建请求，请求方式选择 `GET`。
2. URL 填写 `http://localhost:8080/api/course-opening/page?pageNum=1&pageSize=10`。
3. 如需筛选，在 URL 后继续拼接 `&courseName=Java`、`&semesterId=1` 等参数。
4. 不需要 Body，点击 `Send`。

## 2. 新增开课

### 接口名称

新增开课

### 请求方式

`POST`

### 完整 URL

```text
http://localhost:8080/api/course-opening
```

### 请求参数说明

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| courseId | Body | Integer | 是 | 课程 ID，必须在 courses 表存在 |
| semesterId | Body | Integer | 是 | 学期 ID，必须在 semesters 表存在 |
| teacherId | Body | Integer | 是 | 教师 ID，必须在 teachers 表存在 |
| maxStudents | Body | Integer | 是 | 最大选课人数，必须大于 0 |

请求 Body 示例：

```json
{
  "courseId": 1,
  "semesterId": 1,
  "teacherId": 1,
  "maxStudents": 50
}
```

### 成功返回 JSON 示例

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null
}
```

### 失败返回 JSON 示例

重复开课：

```json
{
  "code": 400,
  "message": "同一学期、同一课程、同一教师不能重复开课",
  "data": null
}
```

外键不存在：

```json
{
  "code": 400,
  "message": "课程 ID [999] 在 courses 表中不存在",
  "data": null
}
```

### Postman 调用说明

1. 新建请求，请求方式选择 `POST`。
2. URL 填写 `http://localhost:8080/api/course-opening`。
3. `Headers` 添加 `Content-Type: application/json`。
4. 选择 `Body -> raw`，粘贴上述 JSON。
5. 点击 `Send`，返回 `code=200` 即新增成功。

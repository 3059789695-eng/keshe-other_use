# 学生 A-01、教师 A-02 使用说明

## 环境

- Spring Boot 3.5.14
- MyBatis 3.0.5
- JDK 17+，本机使用 JDK 21 验证
- 数据库：`localhost:3307/cas`

## 启动

```bash
cd student-manager
mvn spring-boot:run
```

## 学生管理 A-01

### 1. 分页查询学生

```text
GET http://localhost:18081/api/student/page?pageNum=1&pageSize=10
```

可选参数：`studentNo`、`name`、`classId`。

### 2. 新增学生

```text
POST http://localhost:18081/api/student/add
```

```json
{
  "id": 3,
  "studentNo": "2024003",
  "classId": 2
}
```

### 3. 查询学生详情

```text
GET http://localhost:18081/api/student/3
```

### 4. 编辑学生

```text
PUT http://localhost:18081/api/student/update
```

```json
{
  "id": 3,
  "studentNo": "2024003",
  "classId": 1
}
```

### 5. 删除学生

```text
DELETE http://localhost:18081/api/student/3
```

### 6. 模板与导入

```text
GET http://localhost:18081/api/student/template
POST http://localhost:18081/api/student/import
```

导入使用 `multipart/form-data`，字段名 `file`。

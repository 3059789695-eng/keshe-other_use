# 开课管理 T-11 使用说明

## 环境

- Spring Boot 3.5.14
- MyBatis 3.0.5
- JDK 17+，本机使用 JDK 21 验证
- 数据库：`localhost:3307/cas`

## 启动

```bash
cd course-opening
mvn spring-boot:run
```

## 1. 分页查询开课

### 请求 URL

```text
GET http://localhost:18080/api/course-opening/page?pageNum=1&pageSize=10
```

可选参数：`courseName`、`semesterId`、`semesterName`、`teacherName`。

### 成功响应

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "total": 2,
    "list": [
      {
        "id": 1,
        "courseId": 1,
        "courseNo": "1",
        "courseName": "Java程序设计",
        "credit": 4.0,
        "semesterId": 1,
        "semesterName": "2025-2026-1",
        "teacherId": 1,
        "teacherName": "张老师",
        "maxStudents": 50
      }
    ]
  }
}
```

## 2. 新增开课

### 请求 URL

```text
POST http://localhost:18080/api/course-opening
```

### 请求 Body

```json
{
  "courseId": 1,
  "semesterId": 1,
  "teacherId": 1,
  "maxStudents": 50
}
```

### 成功响应

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null
}
```

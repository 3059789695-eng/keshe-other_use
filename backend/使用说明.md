# 用户角色分配 R-02 使用说明

## 环境

- Spring Boot 3.5.14
- MyBatis 3.0.5
- JDK 17+，本机使用 JDK 21 验证
- 数据库：`localhost:3307/cas`

## 启动

```bash
cd user-role-assignment
mvn spring-boot:run
```

## 1. 获取全部角色

### 请求 URL

```text
GET http://localhost:18082/api/user-role/roles
```

### 成功响应

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [
    {
      "id": 1,
      "roleName": "管理员",
      "roleCode": "管理员",
      "description": "系统管理员"
    },
    {
      "id": 2,
      "roleName": "教师",
      "roleCode": "教师",
      "description": "教师角色"
    }
  ]
}
```

## 2. 查询用户已有角色

### 请求 URL

```text
GET http://localhost:18082/api/user-role/user/1/roles
```

### 成功响应

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [1, 2]
}
```

## 3. 分配角色

### 请求 URL

```text
POST http://localhost:18082/api/user-role/user/1/roles
```

### 请求 Body

```json
{
  "roleIds": [1, 2]
}
```

传空数组 `[]` 表示清空该用户全部角色。

### 成功响应

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null
}
```

## 4. 分页查询用户及角色

### 请求 URL

```text
GET http://localhost:18082/api/user-role/users?pageNum=1&pageSize=10
```

可选参数：`username`、`name`。

### 成功响应

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "total": 3,
    "list": [
      {
        "id": 1,
        "username": "zhangsan",
        "name": "张三",
        "roleIds": "1,2",
        "roleNames": "管理员,教师",
        "assigned": true
      }
    ]
  }
}
```
